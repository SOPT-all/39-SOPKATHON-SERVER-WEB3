# ADR 002: CI/CD 구성

- 상태: 초안 — 워크플로 설정은 확인했으나 선택 근거와 대안은 팀 확인 필요

## 배경

변경사항을 검증하고 배포 과정을 팀이 일관되게 실행할 필요가 있다.

## 현재 구성

- CI: `main` 또는 `develop` 대상 PR에서 Java 21로 `./gradlew --no-daemon clean build`를 실행한다.
- CD: `main` push 또는 수동 실행 시, main 브랜치에 한해 테스트 후 Docker 이미지를 빌드·업로드하고 EC2에 배포한다.
- AWS OIDC로 임시 권한을 받아 실행기 IP의 SSH 접근을 일시 허용하고, SSH로 배포한다. 앱 상태와 HTTPS API 문서 응답을 확인하고 SSH 허용 규칙을 제거한다.
- 실제 워크플로 실행 성공 여부는 설정 내용과 별도로 확인해야 한다.

## 고려한 대안 및 선택 이유

- 실제로 고려한 대안과 선택 이유: 팀 확인 필요.

## 영향

- 배포에 필요한 GitHub Secrets, EC2와 Docker Hub 설정이 필요하다.
- 운영 DB 마이그레이션이 포함된 배포는 앱 이미지 복구 시 DB 호환성을 함께 확인한다.

## 미정 사항

- 선택 배경과 대안의 비교 근거 확인.
