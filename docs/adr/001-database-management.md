# ADR 001: DB 및 스키마 관리

- 상태: 초안 — 설정은 확인했으나 선택 근거와 대안은 팀 확인 필요

## 배경

여러 개발자가 스키마를 공유하고 배포 환경에 변경사항을 적용해야 한다.

## 현재 구성

MySQL 8.4를 사용한다. Flyway 마이그레이션을 활성화하고 JPA `ddl-auto: validate`로 매핑을 검증하도록 설정되어 있다. 서비스 마이그레이션은 `src/main/resources/db/migration/`에 버전별로 추가한다.

## 고려한 대안 및 선택 이유

- 실제로 고려한 대안과 선택 이유: 팀 확인 필요.

## 영향

- 스키마 변경 시 엔티티 변경과 별도로 Flyway SQL을 작성해야 한다.
- 이미 적용된 마이그레이션은 수정하지 않고 새 버전으로 변경한다.
- `validate`는 매핑 검증이며 모든 데이터 및 제약 조건의 정확성을 보장하지 않는다.

## 미정 사항

- 선택 배경과 대안의 비교 근거 확인.
