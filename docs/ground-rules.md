# 협업 규칙

## 소통

- 서로 배려하며 이야기하고 공유·수정 사항은 제때 전달한다.
- 1~2시간마다 스트레칭한다.

## Git과 이슈·PR

확정된 브랜치, 커밋·PR 제목, 리뷰 및 머지 규칙은 [README의 Convention](../README.md#convention)을 따른다.

- 작업 전 유형에 맞는 `.github/ISSUE_TEMPLATE/` 템플릿을 사용하고 담당자와 타입 라벨을 지정한다.
- 일반 작업은 이슈 하나, 브랜치 하나, PR 하나로 묶는다.
- PR은 `.github/pull_request_template.md`를 사용하고 관련 이슈를 `Closes #번호`로 연결한다.
- PR에 실제 변경 내용과 검증 결과를 작성한다. 실행하지 못했거나 해당하지 않는 항목은 완료로 표시하지 않고 사유를 공유한다.
- 서버 팀원에게 리뷰를 요청한다. 공통 코드, DB 스키마, 인증·배포 설정 변경은 팀원 확인 후 머지한다.
