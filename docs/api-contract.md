# API 계약

## 공통 규칙

- 공통 응답은 `BaseResponse`를 사용하고 `success`, `code`, `message`, `data`를 포함한다. `code`는 실제 HTTP 상태 코드와 같은 문자열이다.
- 반환할 데이터가 없을 때 `data`는 `null`이다. 요청 값 검증 실패 시 `data`에 필드별 오류가 담길 수 있다. 그 외 공통 실패 응답은 `null`이다.
- 응답에는 엔티티 대신 DTO를 사용한다. 페이지네이션을 사용하는 경우 요청과 응답의 페이지 번호는 1부터 시작하며 `PageResponse`를 활용한다.
- 응답 계약을 변경하면 Swagger도 함께 수정하고 실제 응답과 비교한다.
- 공통 접두사, 인증 및 날짜 형식: 미정. 합의 전 임의로 확정하지 않는다.

```json
{
  "success": true,
  "code": "200",
  "message": "요청 처리 성공",
  "data": null
}
```

위 메시지는 형식 예시이며 API별 실제 메시지는 해당 성공 코드와 명세를 따른다.
